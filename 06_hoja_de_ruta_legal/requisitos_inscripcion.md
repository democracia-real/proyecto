# Requisitos de Inscripción de Partidos Políticos

## Resumen

Requisitos **legales** para inscribir un partido político en España, conforme a la **Ley Orgánica 6/2002 de Partidos Políticos** (LOPP) y normativa complementaria. Este documento detalla pasos, documentación y plazos; para el análisis de la ley, véase [ley_organica_6_2002.md](ley_organica_6_2002.md).

> *"La constitución legal es el primer hito formal del proyecto."* — [timeline_constitucion.md](timeline_constitucion.md)

## Marco Legal

| Norma | Contenido |
|-------|-----------|
| **LO 6/2002** | Ley de Partidos Políticos (art. 1-3: constitución e inscripción) |
| **LO 3/2015** | Modifica LO 6/2002 (estatutos, control económico, disolución) |
| **Ley 39/2015** | Procedimiento Administrativo Común (registros, plazos) |
| **Registro** | Ministerio del Interior — Registro de Partidos Políticos |

## Requisitos de los Promotores (Art. 1 LOPP)

| Requisito | Detalle |
|-----------|---------|
| **Número mínimo** | 3 personas físicas |
| **Edad** | Mayores de edad (18 años) |
| **Capacidad** | Pleno ejercicio de derechos civiles |
| **Nacionalidad** | Españoles o ciudadanos de la UE (reforma LO 3/2015) |
| **Antecedentes** | Sin condena por asociación ilícita o delitos contra las instituciones (Títulos XXI-XXIV CP) |

### Verificación Previa

| Acción | Responsable | Entregable |
|--------|-------------|------------|
| Identificar 3+ promotores idóneos | Fundador | Lista de promotores |
| Verificar requisitos legales de cada uno | Asesor legal | Checklist cumplido |
| Confirmar que no hay incompatibilidades | No pueden ser promotores: menores, condenados por asociación ilícita, militares/jueces en activo (LO 6/2002, art. 1-2) | - |

## Documentación Necesaria

| Documento | Requisitos | Formato |
|-----------|------------|---------|
| **1. Solicitud de inscripción** | Dirigida al Registro de Partidos Políticos | Firmada por promotor designado |
| **2. Acta fundacional** | En escritura pública (notario) | Original, no copia |
| **3. Estatutos** | Conforme a art. 3.2 LO 6/2002 | Incluidos en acta o anexo |
| **4. DNI de promotores** | Copia de los tres mínimo | Se acepta copia compulsada; la presentación telemática del acta con firma electrónica es posible vía registro electrónico del Ministerio del Interior |

### Contenido del Acta Fundacional (Art. 3 LOPP)

| Elemento | Contenido |
|----------|-----------|
| Identificación de promotores | Nombre, apellidos, DNI, domicilio |
| Denominación del partido | Nombre completo y siglas |
| Órganos directivos provisionales | Nombres y cargos |
| Domicilio del partido | Dirección física completa |
| Estatutos | Texto íntegro |

### Contenido Obligatorio de Estatutos (Art. 3.2 LOPP)

| Apartado | Contenido Requerido |
|----------|---------------------|
| a) | Denominación, siglas, símbolo, domicilio, ámbito |
| b) | Requisitos y procedimiento de afiliación |
| c) | Derechos y deberes de afiliados |
| d) | Órganos de gobierno: composición, convocatoria, atribuciones |
| e) | Procedimientos de elección de órganos |
| f) | Régimen disciplinario |
| g) | Procedimiento de modificación de estatutos |
| h) | Régimen de responsabilidad económico-financiera |
| i) | Causas de disolución y destino del patrimonio |

**Requisitos adicionales (LO 3/2015):** Sistema de prevención de conductas ilícitas; responsable de gestión económico-financiera.

## Pasos del Proceso

### Fase 1: Preparación (Mes 1 según [timeline_constitucion.md](timeline_constitucion.md))

| Semana | Actividad | Entregable |
|--------|-----------|------------|
| 1 | Identificar 3+ promotores | Lista |
| 1 | Verificar requisitos legales | Checklist |
| 2 | Primera reunión fundacional | Acta informal |
| 2 | Definir nombre y siglas | Propuestas verificadas |
| 3 | Redactar borrador de estatutos | Borrador v1 |
| 3 | Incluir principios de democracia formal | Revisión |
| 4 | Revisar estatutos con promotores | Borrador v2 |
| 4 | Consultar disponibilidad de nombre | Confirmación |

### Fase 2: Formalización (Mes 2)

| Semana | Actividad | Entregable |
|--------|-----------|------------|
| 1 | Revisión final de estatutos | Estatutos definitivos |
| 1 | Preparar acta fundacional | Borrador de acta |
| 2 | Concertar cita con notario | Cita programada |
| 2 | Designar órganos directivos provisionales | Lista de cargos |
| 3 | **Firma ante notario** | Acta notarial |
| 3 | Obtener copias autorizadas | Documentos |
| 4 | Preparar solicitud de inscripción | Solicitud |
| 4 | Revisar documentación completa | Checklist final |

### Fase 3: Inscripción (Mes 3)

| Semana | Actividad | Entregable |
|--------|-----------|------------|
| 1 | **Presentar solicitud en Registro** | Justificante de entrada |
| 1 | Iniciar trámites fiscales (CIF provisional) | Solicitud |
| 2-4 | Esperar resolución (20 días hábiles) | - |
| 2 | Preparar web provisional | Web borrador |
| 3 | Atender posibles requerimientos | Subsanación si procede |
| 4 | **Recibir inscripción** | Resolución |
| 4 | Publicación en BOE | Automático |

## Plazos

| Fase | Plazo |
|------|-------|
| Examen de documentación por Registro | 20 días hábiles desde entrada |
| Subsanación de defectos | Suspende el plazo |
| Silencio administrativo | Positivo (inscripción automática si no hay resolución) |

## Denominación del Partido

### Prohibiciones

| No puede | Razón |
|----------|-------|
| Inducir a error o confusión | Sobre la identidad |
| Coincidir con otro inscrito | Ni semejarse fonéticamente |
| Usar nombre de partido ilegalizado | Evitar continuidad |
| Usar nombres de personas físicas | Protección de identidad |
| Usar marcas registradas | Propiedad intelectual |

### Verificación Previa

1. Consultar [listado de partidos inscritos](https://infoelectoral.interior.gob.es/es/formaciones-politicas/registro-de-partidos-politicos/acceso-al-listado-de-formaciones-politicas)
2. Verificar que no haya similitud fonética
3. Comprobar que el nombre no esté registrado como marca en la OEPM (Oficina Española de Patentes y Marcas); consulta gratuita en localizador.oepm.es

## Después de la Inscripción

| Obligación | Plazo |
|------------|-------|
| Alta fiscal (CIF) | Inmediato |
| Cuenta bancaria | Inmediato |
| Designar responsable económico | Obligatorio (LO 3/2015) |
| Publicar estatutos en web | Obligatorio (LO 3/2015) |
| Libros contables | Según LO 8/2007 / LO 3/2015 |

## Causas de Denegación

| Causa | Consecuencia |
|-------|--------------|
| Defectos formales subsanables | Requerimiento de subsanación |
| Defectos no subsanados | Denegación |
| Denominación prohibida | Denegación |
| Indicios de ilicitud | Remisión al Ministerio Fiscal |
